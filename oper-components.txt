# Components for the per-component oper-state bindings built by build_pyang_bindings.sh
#
# Format: <component> <schema-path>
#   - one oper bindings file per component: build/<target>/oper/<component>_bindings.py
#     ('-' in the component name becomes '_' in the file name)
#   - repeat a component on several lines to give it several subtrees
#   - paths are '/module:name/name/other-module:name/...'; the prefix is a YANG
#     module name and is needed only where a node comes from a different module
#     than its parent (e.g. augments); choice/case nodes are not part of the path
#   - logs/<target>/unclaimed-state.txt lists state not covered by any path here
